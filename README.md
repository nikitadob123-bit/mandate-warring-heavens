# MANDATE: Воюющие Небеса — Full v1.0

Полноценная оригинальная переработка концепции большой браузерной военно-исторической RPG.

## Масштаб
- 42 сюжетные главы
- 420 операций хроник
- 60 указов
- 85 уровней владений
- 12 военных рангов
- 7 оригинальных царств
- армия, улучшения войск, рынок, разведка, отношения, летопись
- продающая landing page + FAQ
- регистрация / вход
- серверное сохранение прогресса в SQLite
- резервное локальное сохранение браузера

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```

После запуска откройте:
`http://localhost:3000`

## Аккаунты и сохранения
Регистрация работает через `/api/register`, вход через `/api/login`.
Пароли хэшируются bcrypt.
Сессия клиента использует JWT.
Сохранение привязано к `user_id` и хранится в SQLite.

Перед реальным публичным запуском обязательно задайте переменную окружения:
`JWT_SECRET=<длинный-случайный-секрет>`

## v1.2 — телефон / автономный режим

`public/index.html` теперь самодостаточный: CSS и JS встроены в HTML, поэтому интерфейс не разваливается при прямом открытии файла на Android.

Также создан `MANDATE_STANDALONE_PHONE.html` — его можно открыть напрямую на телефоне.

Аккаунты работают в двух режимах:
- **серверный/облачный** — при запуске через Node.js; регистрация и сохранения доступны с разных устройств;
- **локальный** — при прямом открытии HTML на Android; регистрация, вход и отдельные сохранения аккаунтов работают через localStorage на текущем устройстве.

Важно: без сервера технически невозможно синхронизировать данные между разными телефонами/ПК. Поэтому локальный режим полностью работает на одном устройстве, а облачный — после публикации серверной версии.


## v1.3 Boosty Edition

Подключена модель платного доступа через Boosty:

- цена интерфейса: **$3 / месяц**
- ссылка уровня: https://boosty.to/7thdimension/purchase/2906702?ssource=DIRECT&share=subscription_link
- полная кампания блокируется без активного entitlement
- `/api/access` — статус доступа текущего пользователя
- `/api/access/request` — пользователь сообщает, что оформил подписку
- `/api/admin/access/grant` — серверная выдача доступа по email
- `/api/admin/access/revoke` — отзыв доступа
- облачные сохранения доступны только при активной подписке
- локальная автономная HTML-версия не может считаться защищённой платной версией

### Админ-выдача после подтверждения Boosty

Пример запроса:

```bash
curl -X POST http://localhost:3000/api/admin/access/grant   -H "Content-Type: application/json"   -H "x-admin-key: ВАШ_ADMIN_KEY"   -d '{"email":"player@example.com","days":31}'
```

### Автоматизация Boosty

Endpoint `/api/boosty/webhook` оставлен как безопасный адаптер-заглушка. Он **не активирован**, потому что в публично доступной официальной документации Boosty, найденной при сборке, не было подтверждённой схемы webhook/API для статуса подписки. Не следует подключать непроверенные приватные endpoint'ы Boosty.

Когда появится официальная документация/ключи, адаптер должен:
1. проверить подпись события;
2. сопоставить подписчика с игровым аккаунтом;
3. выставить `access_grants.status = active`;
4. обновить `expires_at`;
5. при отмене/истечении выставить `inactive`.


## v1.4 — автоматический Boosty-доступ через Discord

Реализован Discord OAuth2 bridge. После связывания Discord сервер проверяет у пользователя роль,
которую Boosty выдаёт активным подписчикам. Наличие роли автоматически активирует полный доступ,
отсутствие роли его отзывает.

См. `DISCORD_SETUP.md`.
